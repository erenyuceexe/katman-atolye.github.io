# Print Atölyesi Design System

## Direction

**THESIS:** A print request should feel like dropping a well-labeled job ticket into a friendly workshop, not filling out a cold quote calculator.  
**OWN-WORLD:** Cool blueprint blue, ink-black, paper-white, and a single safety-orange signal; crisp ruled lines, stamped labels, and tiny machine-status details.  
**STORY:** The visitor sees the short path, chooses a model and finish, then sends a complete job ticket for a human confirmation.  
**FIRST VIEWPORT:** A dark-blue workbench header frames the value proposition; an order ticket starts immediately below with a live “ready to send” summary.  
**FORM:** Operator-first intake sheet, chosen for clarity over a conventional marketing hero; the print-ticket metaphor carries through fields, chips, and confirmation.

## Tokens

- Ink: `#10151b`
- Workshop blue: `#0b3a5b`
- Blueprint: `#dceaf2`
- Paper: `#f7f8f5`
- Signal orange: `#ff7043`
- Utility green: `#b9e769`
- Fonts: Syne for display and UI; IBM Plex Mono for labels and statuses.

## Rules

- Use squared corners with a small 6px radius; cards should feel like forms, not floating app tiles.
- Keep the primary action orange and the operator status green.
- Use monospaced labels only for status, metadata, and measurements.
- Responsive layout collapses the job ticket and live summary into one column below 900px.
